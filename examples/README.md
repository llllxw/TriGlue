# Examples

`train.csv` and `val.csv` are synthetic labelled input templates for checking training. Their labels have no experimental meaning. `minimal_input.csv` demonstrates unlabelled input. Replace these with your data for scientific use.

`triplets.csv` demonstrates optional identifiers and structure paths. `compounds.csv` and `protein_pairs.csv` are candidate enumeration templates. `prepared_triplets.csv` is a format example requiring its associated features.
